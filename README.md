# Cadastro de Clientes

Trabalho de Linguagem de Programação III. É um cadastro de clientes feito com Java 21, Spring Boot e H2.

Abra o projeto Maven no IntelliJ com Java 21 e rode a classe `CadastroClientesApplication`.

No Postman, teste `GET http://localhost:8080/clients/1`. O banco já começa com 10 clientes de exemplo.

O diagrama da classe está no arquivo `Client.asta`.
